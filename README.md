# Jet Engine AR Simulation

An interactive AR-based jet engine simulation that allows users to visualize, explore, and understand the internal components of a jet engine in real time. The model can be disassembled during runtime to reveal internal structures such as the hull, tubes, and grid components while the simulation remains active.

Designed primarily for iOS devices, the project demonstrates how Augmented Reality can be used for immersive mechanical visualization, education, and engineering demonstration use cases.

---

## ✨ Key Features

- **AR-based visualization**
  - View a jet engine in real-world space using iOS devices.
  
- **Interactive disassembly**
  - Remove engine components (e.g., hull, tubes, grid) while the internal mechanisms continue to operate.
  
- **Real-time simulation**
  - Observe turbine motion and component relationships dynamically.
  
- **Learning/Training context**
  - Suitable for aviation education, mechanical training, demos, and technical presentations.

## 🎮 How to Use

1. Build & deploy to an iOS device.
2. Scan a flat surface and place the engine.
3. Tap UI controls to:
   - Toggle components on/off
   - Trigger disassembly
   - Inspect internal layers
4. Pan, rotate, or move around physically to explore the model in space.
